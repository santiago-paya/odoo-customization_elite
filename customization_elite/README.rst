Instructions
============

Update translations
-------------------

Manually in Settings > Developer mode > Translations

1. Open Settings > Translations > Languages
2. Update languages

Firts time setup
================
   
Set paper format
----------------

1. Open Settings > General Settings > Companies
2. Configure document layout
3. Set Paper format as ``A4 - Elite``

Uninstall instructions
======================

When uninstalling, remember to undo the setup:

1. Undo the paper format setting
